DroidWeather is a fast and simple weather application for Android devices running Android 5.0 or above, it allows for you to have five saved locations and see the current weather, hourly forecast, and a 7-day forecast.
Weather and geocoding data provided by Open-Meteo (https://open-meteo.com/).
This project was created with help from Artificial Intelligence (Google Gemini 3.6 Flash).
In the future it is planned to receive support for Android 2.2 and above, and should hopefully support Android 4.2 and above by 01/11

Tested with:
Motorola Moto E Gen 2 running Android 5.0.2 (100% Working)
Samsung Galaxy S4 Mini running Android 4.4.2 (App opens, security and formatting errors)
